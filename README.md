# SkillDzire Certificate Verification Page

A responsive HTML/CSS recreation of the supplied screenshot.

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in your browser.

## Customize
Edit the certificate ID, student name, course name, and issue date in `index.html`.
This is a front-end recreation; it does not change the original SkillDzire website or verify certificate records.
